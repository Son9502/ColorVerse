How to use ColorVerse

3-D controls

Drag or ←↑→↓
Rotate the object
Scroll
Zoom in / out
[ ]
Previous / next layer
1–6
Snap to a face / axis
Click
Pick the color under the cursor
Double-click
Reset rotation and zoom
Esc
Clear the selected color

Panel tools

HSL toggle
Switch the object between RGB and HSL color spaces
Shape
Cube or sphere
Dimension
3-D now; 1-D and 2-D views are coming soon
Layer
Type 0–127 to preview a layer, Enter to jump there. Layer 0 is the outer surface, 127 is the gray core
Color Search
Find any of ~4,000 named colors. Enter completes the best match, Enter again selects it. Or pick with ↑↓ + Enter
Color details
Hex, RGB, and HSL values of the selected color. The active color space is bold and listed first
Harmonies
Complementary, triadic, analogous, tints, shades, tones, saturate and more. Double-click a swatch to make it the selected color; click ▾ to collapse a row
Mini shape
Bottom-right; shows the current orientation and where the picked color sits
