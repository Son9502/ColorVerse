How to use ColorVerse

3-D controls

Drag or ←↑→↓
Rotate the object
Scroll
Zoom in / out
[ ]
Previous / next layer
1–6
Snap to a face / axis
Click
Pick the color under the cursor
Double-click
Reset rotation and zoom
Esc
Close this panel, cancel the text box you're in, or go back to Color Search

Panel tools

HSL toggle
Switch the object between RGB and HSL color spaces
Shape
Cube or sphere
Dimension
3-D now; 1-D and 2-D views are coming soon
Layer
Type 0–127 to preview a layer, Enter to jump there. Layer 0 is the outer surface, 127 is the gray core
Color Search
Find any of ~3,200 named colors. Enter completes the best match, Enter again selects it. Or pick with ↑↓ + Enter. Click the empty box to see your last 10 searches
Color details
Replaces Color Search once a color is selected: hex, RGB, and HSL values, with the active color space bold and listed first. ← Search, Esc, or clicking empty canvas goes back
Sliders
Fine-tune the selected color: H/S/L when the HSL toggle is on, R/G/B when it's off. Each track previews what that slider will do
Harmonies
Complementary, triadic, analogous, tints, shades, tones, saturate and more. Double-click a swatch to make it the selected color; click ▾ to collapse a row
Mini shape
Bottom-right; shows the current orientation and where the picked color sits

Welcome to ColorVerse

Most color pickers flatten color into a wheel. But color has three dimensions: RGB is a cube, and HSL is a cylinder.

ColorVerse lets you rotate those spaces, peel them apart layer by layer, and pick any color to explore its harmonies.
